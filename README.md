Address Book – C Project

📌 Project Description

The Address Book is a menu-driven application developed using the C programming language. It allows users to manage contact information by performing operations such as creating, searching, displaying, editing, and deleting contacts.

The project uses file handling to store contact details permanently so that the data can be accessed even after the program is closed.

✨ Features

- Create Contact: Add a new contact with name, phone number, and email address.
- Search Contact: Search for contacts using name, phone number, or email.
- List Contacts: Display all saved contacts.
- Edit Contact: Update existing contact information.
- Delete Contact: Remove a contact from the address book.
- Save and Load: Store contacts in a file and load them when the program starts.

🛠️ Technologies Used

- C Programming
- Structures
- Pointers
- Functions
- File Handling
- String Manipulation

📂 Project Structure

- "main.c" – Main program and menu
- "contact.c" – Contact management operations
- "contact.h" – Function declarations and structure definitions
- "file.c" – File saving and loading operations
- "contacts.txt" – File used to store contact information

▶️ How to Compile and Run

1. Clone the Repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the Project Directory

cd AddressBook

3. Compile the Program

gcc main.c contact.c file.c -o addressbook

4. Run the Program

./addressbook
